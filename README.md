# Brasa Viva

Projeto conceito de site para churrascaria, criado pela **Growthfy Tech** para portfólio.

- Abertura com braseiro animado: carvões acesos e fagulhas que reagem ao mouse
- Cardápio prato por prato, com fotos grandes que se abrem ao rolar
- Botões fixos de reserva e pedido no WhatsApp
- Reserva que monta a mensagem pronta para enviar no WhatsApp
- Responsivo para celular

Site estático em um único arquivo (`index.html`), pronto para publicar na Vercel, Netlify, GitHub Pages ou Hostinger.

> Restaurante, endereço, telefone e preços são fictícios. Fotos: Unsplash.
